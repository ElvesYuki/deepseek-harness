# 桌面启动器维护

[English](guide.md) | 中文

## 变更

`desktop-launcher/` 中的独立启动器在当前程序目录原地更新。更新会停止服务，不再创建程序或用户数据备份。分离的准备和切换操作改为“更新并启动”“修复当前版本”和“恢复内置版本”。默认更新渠道改为正式发布版，不再默认包含预发布版。数据导入保留独立的备份行为。

已有 active 目录继续使用。已准备版本及历史备份保留在磁盘，但不会由新的更新按钮激活。中断的维护会阻止启动，直到修复或恢复成功。恢复只替换程序文件，不能逆转新版 DSH 执行的数据迁移。

全新安装的正式客户端需要先部署运行目录才能普通启动。macOS 请运行 DMG 内的安装命令；Windows Setup 在完成前执行部署。已有运行目录保持不变。参见[安装说明](../../../../desktop-launcher/README.zh.md)。

## 迁移

1. 更新启动器前结束正在运行的任务。用户配置和项目文件应放在托管程序目录以外：维护会重置源码并移除程序目录中的生成文件或未跟踪文件。
2. 在更新页面选择正式发布版、包含预发布版或主分支最新版。没有正式版时会明确提示，不替换为预发布版。
3. 更新中断后选择修复或重试维护操作。需要离线恢复程序时，选择恢复内置版本。这些操作都不恢复或删除用户数据；如果旧程序无法读取现有数据，请使用兼容的新版本。
4. 确认管理窗口显示预期版本及 commit，并能打开工作区。排查失败时保留现有数据和历史备份。参见[启动器维护说明](../../../../desktop-launcher/README.zh.md)。
